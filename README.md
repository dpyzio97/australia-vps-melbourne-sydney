## 常见问题

**能装 Windows 吗？**
官网澳洲产品页没有列出 Windows 选项，现有资料也没确认支持。需要 Windows 就下单前发工单问清楚，别默认可以。

**IP 会不会被标记？**
IP 质量随时间变化是常态。WePC 其他节点有过上游变更后部分数据库标记风险 IP 的记录，新加坡和越南都有类似反馈。澳洲这边，墨尔本在 2026 年 3 月的测评里 IP 质量评价仍然很高，是澳洲两条线里更稳的一条。真被标记了，换 IP 收费 4 澳元。

**一定要中转吗？**
官方说墨尔本“直播无需中转”，推流场景可以直接用。你要在国内频繁操作桌面、传文件，才需要考虑中转。

**续费会涨价吗？**
现有资料里没有澳洲产品续费涨价的记录，价格以澳元计价，续费主要受汇率影响。年付锁定的是当期价格，但如前所述，这个年付本身没折扣。

**流量超了怎么办？**
部分机房超流量后限速 5Mbps，澳洲产品是否适用没有明确确认，2TB 双向流量对直播场景通常够用，跑大流量分发要提前问。
